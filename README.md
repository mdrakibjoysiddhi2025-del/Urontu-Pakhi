# Urontu-Pakhi
"Urontu Pakhi" is a fun and challenging arcade game built with Python! 🐍✨  Tap the Spacebar ⌨️ to flap the bird's wings 🐦 and keep it airborne. Navigate carefully through the narrow gaps between the green pipes 🪵 without crashing! 💥  How high can you score 🏆 before wiping out? 📉 Play now and challenge your friends! 🔥
